# Programação Orientada a Objetos
Esse arquivo contém as respostas das questões teóricas da atividade introdutória à classe de **Programação Orientada à Objetos**, mestrada pelo Professor Paulo César.

O [arquivo `.py`](./answers.md), neste mesmo diretório, possuí as respostas para a parte, de fato, prática da atividade.

## Questões

### Questão Nº 1

**Qual das alternativas abaixo melhor define o termo “classe”?**\
~a) Uma coleção de variáveis e funções trabalhando com essas variáveis.~\
b) Define e obtém as propriedades e métodos dela.\
c) É a personificação de um objeto da vida real.\

### Questão Nº 2

**Qual das alternativas abaixo melhor define o termo “objeto”?**\
~a) Um objeto nos dá a capacidade de trabalhar com a classe e ter várias instâncias desta mesma classe.~\
b) Uma variável dentro de uma classe.\
c) Uma função dentro de uma classe.\

### Questão Nº 3

**Qual das alternativas abaixo melhor explica o termo "propriedade"?**\
a) Agrupa o código relacionado a um tópico.\
~b) Uma variável dentro de uma classe.~\
c) Uma função dentro de uma classe.\

### Questão Nº 4

**Qual das alternativas abaixo melhor explica o termo "método"?**\
~a) Uma função dentro de uma classe.~\
b) Uma variável dentro de uma classe.\
c) A incorporação de uma ação real.\

### Questão Nº 5

**Escreva o que você acha que deveria ser o nome da classe, os nomes das propriedades para o primeiro e último nome (sobrenome) e o nome do método que retorna “Olá”.**\
Nome da classe: *Usuário*\
Propriedades: *nome* , *sobrenome*\
Método: *saudacao*
